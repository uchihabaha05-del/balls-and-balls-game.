# ТакеМЯЧ — вызов Таирбека ⚡

Аркадная игра для друга Таирбека: 10 уровней, цветные мишени, рикошеты, очки и личный рекорд.

## Играть в браузере
Открой GitHub Pages после включения Pages в Settings → Pages → Deploy from a branch → main → /(root).

## Скачать Android APK
Каждый push запускает GitHub Actions workflow **Build Android APK**. Открой вкладку Actions, выбери успешный запуск и скачай артефакт **TakеMYACH-debug-apk**. Внутри будет APK для установки на Android. Для установки может потребоваться разрешить установку приложений из выбранного источника.

## Управление
Проведи пальцем/мышью от мяча в направлении, противоположном желаемому полёту, и отпусти. Разбивай мишени, проходи 10 испытаний и набирай рекорд!
