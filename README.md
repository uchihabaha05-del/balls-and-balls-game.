# TRAPTAG

**BUILD IT. TRAP IT. BEAT IT.**

TRAPTAG — мобильный 3D-платформер и конструктор уровней. Этот репозиторий — ранний браузерный прототип, который сохраняет PWA/Capacitor-основу прежнего проекта.

## Что уже есть в прототипе
- 3D-сцена на Three.js с камерой, освещением и сеткой
- Режим строительства: размещение платформ по сетке
- Режим ловушек: шипы, пила и лазер
- Выбор объектов, поворот на 45° и удаление
- Тестовый запуск: ходьба, прыжок, столкновения, финиш и падение
- Сенсорные кнопки для мобильного управления
- Сохранение уровня в localStorage и экспорт/импорт JSON через файл

## Запуск
Открой `index.html` через локальный веб-сервер (ES modules не работают надёжно через file://). Например:

```bash
python -m http.server 8080
```

Затем открой http://localhost:8080. Для загрузки Three.js требуется интернет.

## Android
Capacitor config сохранён с новым appId `com.traptag.game`. Для сборки Android нужны Node.js, Android Studio/SDK и папка Android-проекта Capacitor. APK пока не собран и не проверен.

## Ограничения прототипа
Это ранняя игровая основа, а не готовый релиз: физика упрощённая, ловушки пока статичны, сетевой обмен уровнями/аккаунты/таблицы лидеров ещё не подключены. Уровни сохраняются локально на устройстве.
