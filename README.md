# TRAPTAG

**BUILD IT. TRAP IT. BEAT IT.**

TRAPTAG — мобильный 3D-платформер и конструктор уровней. Этот репозиторий — ранний браузерный прототип, который сохраняет PWA/Capacitor-основу прежнего проекта.

## Что уже есть в прототипе
- 3D-сцена на Three.js с камерой, освещением и сеткой
- Режим строительства: размещение платформ по сетке
- Режим ловушек: шипы, пила и лазер
- Выбор объектов, поворот на 45°, копирование, изменение высоты и удаление
- Тестовый запуск: ходьба, прыжок, столкновения, финиш и падение
- Сенсорные кнопки для мобильного управления
- Сохранение уровня в localStorage и экспорт/импорт JSON через файл
- Улучшенное приземление на платформы, вращающиеся и патрулирующие пилы, периодически отключающийся лазер

## Запуск
Открой `index.html` через локальный веб-сервер (ES modules не работают надёжно через file://). Например:

```bash
python -m http.server 8080
```

Затем открой http://localhost:8080. Для загрузки Three.js требуется интернет.

## Android
Capacitor config сохранён с новым appId `com.traptag.game`. Debug APK успешно собран через GitHub Actions для исходного коммита прототипа. После переноса в `main` запускается повторная сборка; APK нужно установить и проверить на реальном Android-устройстве перед использованием.

## Ограничения прототипа
Это ранняя игровая основа, а не готовый релиз: физика остаётся упрощённой, поведение ловушек базовое, сетевой обмен уровнями/аккаунты/таблицы лидеров ещё не подключены. Пилы и лазеры получили простую анимацию; это не полноценная физическая модель. Уровни сохраняются локально на устройстве.
